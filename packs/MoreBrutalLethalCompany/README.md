<h1 align="center">Perfect Balance of Challenge and Fun</h1>

<p align="center">
  <b>Balanced Difficulty • Vanilla feel • 4-16 players</b><br>
  <i>300+ mods • 55 moons • 8 Systems • 30+ enemies</i>
</p>

<p align="center">
   <i>MoreBrutalLethalCompanyPlus is a complete revamp in quality of life for Lethal Company, <b>improving, rebalancing, and expanding</b> upon it while keeping the vanilla feel. The focus of this modpack is to create a <b>difficult yet fair</b> experience, suitable for casual and competitive play.</i>
</p>

> <p align="center">
>   <i>Whether you are an intern or leader, MBLCP delivers the gameplay depth the Company demands.</i>
> </p>

<p align="center">
  <i>MBLCP comes with common defaults but also offers optional tweaks for players who want them.</i>
</p>

| Feature | Config File | Default | Notes |
|---------|-------------|---------|-------|
| **BepInEx Console** | `BepInEx.cfg` | `false` | Enable/disable BepInEx console |
| **Loading Screen** | `Bertogim.LoadingScreen.cfg` | `true` | Enable/disable loading screen |
| **DMCA-Free Radio** | `scandal.scanvan.cfg` | `false` | Streamer-safe music, disables live-radio |
| **Fog Quality** | `butterystancakes.lethalcompany.chameleon.cfg` | `High` | Increases performance by lowering the quality |
| **Graphics Quality** | `LethalSponge.cfg` |  | <details><summary>Multiple options available</summary><br><i>Lower for performance, higher for quality</i><br><br>• Decal atlas size (default: 2048)<br>• Reflection atlas size (default: 2048×2048)<br>• Shadows max resolution (default: 512)<br>• Shadows atlas size (default: 4096)</details> |
| **Resolution & UI Scaling** | `LCUltrawide.cfg` |  | <details><summary>Multiple options available</summary><br><i>Lower for performance, higher for quality</i><br><br>• Gameplay rendering multiplier (default: 1.4)<br>• Terminal rendering multiplier (default: 1.4)<br>• HUD scale (default: 1, range 0.5-1.5)<br>• HUD aspect ratio (default: 0 / auto)</details> |
| **Crosshair** | `com.ctnoriginals.crosshair.cfg` | `•` | Change crosshair appearance |

> 📝 Some options are **host-only** - all clients must apply the same changes to avoid sync issues
